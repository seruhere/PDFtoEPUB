Building a PDF to EPUB converter for Android using Flutter (Dart) and Kotlin.
Goals:
1. Modern UI (Flutter Material 3).
2. Fully fledged EPUB reader.
3. Accurate preservation of PDF headings, sub-headings, and images.

**Research Findings:**
- PDF parsing is best handled off-device or via optimized native libraries.
- EPUB structure is best generated using XHTML/CSS standards.
- UI will be Flutter (Material 3) with a WebView-based reader or native FolioReader-Android integration.

**How to apply:** Maintain Flutter architecture while integrating native Android (Kotlin) for performance-critical PDF conversion tasks if needed.
